4. Use this in your own program

All the speech-to-text work is in one file, whisper-stt.js. This page is just one program that uses it. Any other web page can use it the same way: give it an audio file and get text back.

Step 1: Copy these into your program's web folder

  • whisper-stt.js: the speech-to-text engine.
  • The models/ folder: the Tamil and Malayalam fine-tuned models. Keep it next to whisper-stt.js. Without it, everything still works, but Tamil and Malayalam use standard Whisper.

Step 2: Add this to the page where users upload a voice file

<input type="file" id="voiceFile" accept="audio/*,video/*">
<p id="transcript"></p>

<script type="module">
  import { WhisperSTT } from './whisper-stt.js';

  const stt = new WhisperSTT();
  stt.load();   // starts loading the model as soon as the page opens

  document.getElementById('voiceFile').onchange = async (event) => {
    const file = event.target.files[0];
    document.getElementById('transcript').textContent = 'Converting…';

    try {
      const result = await stt.transcribe(file);   // language is auto-detected
      document.getElementById('transcript').textContent = result.text;
    } catch (error) {
      document.getElementById('transcript').textContent = 'Could not convert: ' + error.message;
    }
  };
</script>

That's all that's required. transcribe() accepts any audio Chrome can play (mp3, wav, m4a, webm, ogg, and the sound track of mp4 videos).

Step 3 (optional): Choose the language or translate

await stt.transcribe(file, { language: 'ta' });         // force Tamil (skips auto-detect)
await stt.transcribe(file, { language: 'hi' });         // force Hindi
await stt.transcribe(file, { task: 'translate' });      // English translation of any language

Language codes: hi Hindi, ta Tamil, te Telugu, kn Kannada, ml Malayalam, mr Marathi, bn Bengali, gu Gujarati, pa Punjabi, ur Urdu, en English. The full list of 99 is LANGUAGE_NAMES in whisper-stt.js.

What you get back

{
  text: "வணக்கம் எனக்கு ...",           // the transcript
  language: "ta",                       // language used
  detected: true,                       // true if it was auto-detected
  model: "vasista22/whisper-tamil-small", // fine-tuned model used, or null for standard Whisper
  seconds: 4.8,                         // length of the audio
  ms: 3200                              // time taken to transcribe
}

Step 3b (optional): Translate the text into another language

const result = await stt.transcribe(file);
const hindi = await stt.translate(result.text, { from: result.language, to: 'hi' });
console.log(hindi.text);   // the Hindi translation

This works between any two languages in NLLB_CODES (all the Indian languages above, English and about 25 others), offline. If you used task: 'translate', the text is already English, so pass from: 'en'.

Where it can, it uses Chrome's built-in translator (about 250 MB of memory, a few milliseconds). That covers Hindi, Tamil, Telugu, Kannada, Marathi, Bengali, English and most world languages. Chrome downloads each language the first time, and only allows that from a click, so call this from a click handler (for example when the user picks the target language):

button.onclick = () => stt.prepareTranslation('ta', 'hi');   // one-time download of Tamil → Hindi

Other pairs (Malayalam, Gujarati, Punjabi, Urdu, Assamese, Nepali, Sindhi, Sanskrit), and pairs Chrome has not downloaded yet, use Meta's NLLB-200 model instead: about 900 MB to download the first time and up to 4 GB of memory while translating. translate() returns engine ('chrome' or 'nllb') and chromeNeedsClick: true when calling prepareTranslation() from a click would let Chrome take over that pair.

Step 4 (optional): Send the text to your server

const result = await stt.transcribe(file);
await fetch('/api/answers', {             // replace with your own endpoint
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: result.text, language: result.language }),
});

If your program is not a web page (Python, PHP, Java, Node server…)

The model only runs inside Chrome, so your server can't call it directly. Use the "transcription station" setup: keep one Chrome page open on the GPU PC that asks your server for new recordings, converts them, and sends the text back. Your server needs two endpoints (the names below are examples):

<script type="module">
  import { WhisperSTT } from './whisper-stt.js';
  const stt = new WhisperSTT();
  await stt.load();

  while (true) {
    // 1. Ask your server for the next recording. Expected reply: { id, audioUrl, language } or null.
    const job = await (await fetch('/api/next-recording')).json();
    if (!job) { await new Promise(r => setTimeout(r, 5000)); continue; }   // nothing new: wait 5 s

    // 2. Download the audio and convert it to text.
    const audio = await (await fetch(job.audioUrl)).blob();
    const result = await stt.transcribe(audio, { language: job.language || '' });

    // 3. Send the text back.
    await fetch('/api/transcripts', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ id: job.id, text: result.text, language: result.language }),
    });
  }
</script>

Requirements

  • Chrome (or Edge) on a PC with a graphics card. Without one it falls back to the CPU, which is slower. To force the CPU (about 1 GB less memory), use new WhisperSTT({ device: 'wasm' }), or open this page as ?device=cpu.
  • The server should send the headers Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: credentialless (server.js does). Then the CPU mode uses several cores, about 3× faster.
  • The page must be opened from http://localhost or an https:// address, not by double-clicking the file. On this PC, start.command does that.
  • Load whisper-stt.js from the same website as your page. If models/ is on another address, pass it: new WhisperSTT({ modelsUrl: 'https://…/models/' }).
  • The first load downloads about 410 MB. The Tamil and Malayalam models (about 400 MB each) load only when that language comes up, only one of them is kept in memory at a time, and it is freed again after 60 seconds without a clip. Translation adds about 900 MB, loaded when first used and also freed after 60 idle seconds. Change the delays with new WhisperSTT({ languageModelIdleSeconds: 60, translationIdleSeconds: 60 }) (Infinity keeps a model loaded), or free memory at once with stt.freeLanguageModel() and stt.freeTranslation(). Chrome keeps the downloads, so later loads take seconds.
  • Call load() once when the page opens, and reuse the same stt for every file. Files sent at the same time are processed one after another.
